# NightCity — Graphics, Lighting & Environment

This document describes the rendering stack of NightCity: the four HLSL shaders, the environment
engine (`env.lua`) that owns light and weather, the uniform contract between Lua and HLSL, and every
knob the designers / server owners have.  Everything here is verified by `validate.py` (shader
contract + budgets) and `mta_lua_test_nc.py` (runtime behaviour against the strict MTA API stub).

The visual target is a **photoreal, cinematic night city**: a dense neon metropolis in heavy rain,
skyscraper silhouettes with lit windows, mirror-wet streets, volumetric-looking god rays and a
dynamic sky that runs from dawn over hard noon into a long electric blue hour and deep night.

---

## 1. The stack

| piece | file | what it does |
|---|---|---|
| environment engine | `env.lua` | clock, sun/moon, 6-key timecycle, weather presets, wetness/puddles, lightning, vanilla-world fallback.  Pure state + maths, no engine calls except inside `pcall` in `apply()` |
| sky shader | `sky.fx` | full-screen-style dome shader: analytic sun disc, two procedural cloud layers, horizon haze, star field, blue-hour gradient, lightning flash, night-time horizon glow.  Runs on the `nc_skydome` model |
| wet surfaces | `wet.fx` | 55 instances, one per TXD texture: screen-space reflections, puddle mask, specular sun/street lights, rain ripples + splashes, neon emissive boost, tunnel darkening |
| water | `water.fx` | the `waterclear256` GTA texture: animated normals, reflection tint + blur, fresnel, rain rings, foam |
| cinematic grade | `post.fx` | full-screen grade over `dxGetTextureScreenSource`: filmic tone curve, dual polar vignette, chromatic aberration, blue-hour split tone, screen-space god rays, film grain |
| orchestration | `client.lua` | creates/destroys the shaders (`/ncfx`), ticks `env.lua` every frame (`envFrame`), pushes the uniforms, rides the dome on the camera, tunnel detection, ambience audio |

Everything is generated by `python3 build.py` into `../resource/NightCity/`; the shaders and scripts
above are copied from `source/` on every build.

## 2. Uniform contract (Lua → HLSL)

All four shaders share one **common environment block** (declared in the same order in each file) so
a single `pushUniforms` call can drive every effect:

| uniform | type | pushed to | meaning |
|---|---|---|---|
| `gSunDir` | float3 | sky, wet, water, post | direction **to** the sun/moon, xyz (z < 0 at night = moonlight) |
| `gSunCol` | float3 | " | light colour, intensity folded in |
| `gSunI` | float | " | 0..1 sun intensity (0 = night) |
| `gZen` / `gHor` | float3 | " | sky zenith / horizon colours |
| `gNight` | float3 | " | x = night factor, y = blue-hour factor, z = star factor |
| `gCloudCover` | float | " | 0..1 cloud coverage |
| `gWet` / `gPuddle` | float | " | surface wetness / standing water |
| `gExposure` | float | " | shared exposure (used by water) |
| `gTime` | float | " | seconds — **pushed every frame** (drives rain rings) |
| `gFlash` | float | " | lightning 0..1 — **pushed every frame** |
| `gQuality` | float | " | 0..3 (low/med/high/ultra) — shader branch selector |
| `gHaze` / `gMie` | float | " | horizon haze strength / mie g |
| `gWaterTint` | float3 | " | what the GTA water reflects |
| `gRayStrength` | float | " | god-ray strength (peaks at blue hour) |
| `gTun` | float4 | wet | tunnel AABB (x0, y0, x1, y1) |
| `gTunZ` | float2 | wet | tunnel floor / ceiling z |
| `gRoad` | float | wet | road-wetness multiplier |
| `gSurface` | float6 | wet | per-material-class: wet, refl, spec, gloss, ring, emissive |
| `gScreen` | texture | wet, post | `dxCreateScreenSource` of the frame |
| `gTexture0` | texture | sky | the cloud noise sheet (`files/fx/sky_noise.png`) |

Two push paths exist for performance:

* `pushOne(sh, U)` — the slow values (everything except `gTime`/`gFlash`), recomputed on a 0.12 s
  cadence or whenever a lightning flash is live;
* `pushFast(sh, U)` — `gTime` + `gFlash` only, every frame.

`validate.py` proves every `dxSetShaderValue` name exists in the target `.fx` and that all four
files declare the common block.

## 3. Time of day (`env.lua` timecycle)

The sun runs on real seconds: `/ncdaycycle <hours-per-minute>` (default `0.02` ≈ one GTA day per
~20 min, `0` freezes, up to `240`).  `/nctime <h> [m]` jumps the clock and freezes it.

A full sun arc is defined by **6 keyframes** (`KEYS` in `env.lua`):

| key | hour | sun | look |
|---|---|---|---|
| `night` | 0.0 | deep below | pitch-dark sky, stars, strongest neon glow |
| `dawn` | 5.2 | grazing | cold grey-violet, low fog, city windows still lit |
| `morning` | 8.0 | 22° | crisp low sun, clean shadows, wet glints |
| `noon` | 12.0 | 65° | bright, pale blue, hard light |
| `golden` | 18.3 | 5.5° | warm gold rim light, long shadows |
| `blue` | 19.6 | −3.5° | electric blue hour: warm windows vs cool sky (the signature frame) |

Interpolation is **Catmull-Rom on azimuth/elevation, linear on colours**, wrapping around midnight.
Every derived value is computed per frame in `NC_ENV.uniforms()`:

* sun direction: `(cos el · sin az, cos el · cos az, sin el)` — below the horizon the engine flips
  to a **moon** vector and hands out moon colour + `gNight.z = 1` (stars);
* `gNight.x` = night factor (1 at `night`), `gNight.y` = blue-hour factor (peaks at 19:36);
* god-ray strength = blue-hour peak × sun elevation × weather dimming.

## 4. Weather

Preset-driven, eased with different time constants per axis (sun ~1.2 s, sky/sun colour ~3.5 s,
cover ~7 s, wetness follows physics, see below).  `/ncweather <preset>`:

| preset | clouds | rain | wet → puddle | fog | flash | note |
|---|---|---|---|---|---|---|
| `clear` | 0.12 | 0.07 | 0.25 → 0.05 | 3800 | 0 | hard sun |
| `cloudy` | 0.55 | 0 | 0.35 → 0.10 | 2600 | 0 | soft light |
| `rain` | 0.85 | 0.75 | 0.95 → 0.75 | 1400 | 0.08 | wet streets |
| `storm` | 1.0 | 1.0 | 1.0 → 1.0 | 900 | 0.5 | default boot state |
| `fog` | 0.40 | 0 | 0.45 → 0.15 | 420 | 0 | thick horizon |
| `neon` | 0.35 | 0.15 | 0.70 → 0.55 | 1900 | 0 | clear air, glow-heavy night |

The preset only names the target — the sky **transitions** over a few seconds (`gCloudCover` eases
with τ ≈ 7 s).  `/ncrain <0..1|auto>` overrides the rain level (also drives the vanilla rain
streaks); `auto` hands it back to the weather.

### Wetness physics

`gWet` never snaps (except manual override): it soaks up toward the target at
`min(1, dt·(0.22 + 0.45·rain))` and **dries** at `0.006 + 0.030·sun·(1 − 0.65·cover) + 0.004·(1 − cover)`
per second (×1.7) — a street stays mirror-wet long after the rain stops.  Puddles dry 0.35× as fast.
`/ncwet <0..1|auto>` overrides.  Target when raining = `min(1, rain × 1.15)`.

## 5. Lightning

While the active weather has `flash > 0`, the scheduler fires strike clusters every
`4.5–13.5 s / flash` (halved rate on `low` quality).  A cluster = 2–3 spikes over ~0.4 s; each spike
decays at 2.6/s into `gFlash` (all shaders use it: sky brightens, the wet street reflections and the
grade flare).  `NC_ENV.onFlash` in `client.lua` whitens the vanilla sky gradient for 240 ms and
plays thunder after a 0.7–3.2 s sound-travel delay (the delay is what sells it).  `/ncflash`
fires a strike on demand.

## 6. Quality levels

`/ncquality <low|medium|high|ultra>` (default `high`):

| | billboards / frame | sprites | wet rings | cloud octaves | god rays | grain | noise taps | flash |
|---|---|---|---|---|---|---|---|---|
| low | 110 | 150 | off | 2 | off | off | 3 | ×0.5 |
| medium | 220 | 260 | on | 3 | on | off | 4 | ×1 |
| high | 340 | 380 | on | 4 | on | on | 5 | ×1 |
| ultra | 520 | 520 | on | 5 | on | on | 6 | ×1 |

The value is also pushed as `gQuality` so the shaders themselves can drop octaves/taps.

## 7. The sky dome

`nc_skydome` is an inverted icosphere (radius 130) with one `nc_sky_noise` texture.  It is
**collisionless**, always in dimension 0, and `envFrame` repositions it on the camera every frame —
the sky is literally painted around the player 900 m above the map.  All dome geometry normals are
inward (verified numerically on the generated mesh) so `sky.fx` can tell sky from nothing.

Sky pass structure (`sky.fx`):

1. **base gradient** — horizon colour (weather-dimmed) + boosted zenith, with lightning flash lift;
2. **clouds** — two scrolling octaves of the RGB noise sheet (R broad billows, G mid detail), shaped
   by `gCloudCover`, silver-lined toward `gSunDir`, dissolving into `gHaze` at the horizon;
3. **sun** — analytic disc with limb darkening ×3 bloom, only above the horizon;
4. **stars** — hash-grid sparkle ×`gNight.z`, hidden by clouds;
5. **city glow** — `gNight.x` band above the horizon (light pollution / neon dome) shifted toward
   magenta at blue hour.

## 8. Wet streets (`wet.fx`)

One shader instance per TXD texture (55 of them), each configured from `NC_SURFACES`
(texture name → `ground / concrete / metal / glass / wall / neon`, generated by `build.py`).  Per
class: wetness factor, reflectivity, specular, gloss, ripple amount, emissive boost.  Highlights:

* **screen-space reflections** — the previous frame (`gScreen`) is sampled with a normal-driven
  offset and Fresnel weight, so neon signs and headlights smear across the asphalt;
* **puddles** — low-frequency mask thresholded at `gPuddle`, stronger normal ripples + sky
  reflection inside them;
* **rain ripples** — procedural expanding rings in world space (speed from `gTime`, rain level
  scales density/alpha) plus micro surface noise ("hiss");
* **night emissive** — albedo windows/neon pushed up ×`gNight.x` (per-class `gSurface.e`);
* **tunnel** — inside the `gTun`/`gTunZ` volume: rain rings off, reflections dampened, a faint
  ceiling light band (`gTun.y` side bias).

## 9. Grade (`post.fx`)

Filmic tone curve (per-channel with a luminance knee), the blue-hour split tone (cool shadows,
warm highlights), dual polar vignette, 5-tap chromatic aberration ramping to the corners,
time-hashed film grain, and **god rays**: radial blur of the bright frame toward the sun's screen
position with a horizontal gate (so the towers break the rays into shafts).

## 11. Shader targets & failure behaviour

Each `.fx` ships `technique tec0` (`vs_3_0`/`ps_3_0`) plus an empty `technique fallback`.  `post.fx`
also has `technique tec1` (`ps_2_0`) — a lean grade for shader model 2 cards.  **MTA compiles every
technique in the file when the effect is created**, so the `ps_2_0` path must always fit the 64
arithmetic-slot budget of `ps_2_0` or the whole shader fails on every machine (that is exactly what
`error X5608` means).  Two rules follow — both enforced by `validate.py`:

* never use the two-argument `atan(y, x)` — old fxc rejects it; use `atan2(y, x)`;
* anything compiled for `ps_2_0` stays lean (the validator warns above ~12 transcendental calls).

Failure behaviour at runtime:

* shaders compile-fail or the shader model is too old (`fallback` technique) → the city runs
  without them and `/ncfx` says so; a partial failure keeps the reduced set and reports it;
* `glow.png` missing → no billboards (the rest of the city is unaffected);
* audio missing → silent ambience, no errors;
* the environment engine is pure Lua state: if nothing else works, `NC_ENV.apply()` still paints a
  correct vanilla sky/fog/rain/clock for the current time and weather.

## 12. Tuning cheat-sheet

* **look of the night** — `KEYS.night` colours in `env.lua` (zenith/horizon/sun/window/road/water);
* **neon punch** — `nightGlow` per key + `gSurface.e` per class + `NC_SURFACES` grouping;
* **rain feel** — `WEATHERS` table (cover/rain/wetT/fog/flash) + the soak/dry rates in `stepWet`;
* **blue hour length** — the `dawn`/`blue`/`night` key hours;
* **god rays** — `k.mie` + `rayStrength` weighting in `NC_ENV.uniforms()`;
* **reflections** — `GROUP_PARAMS` in `client.lua` and the Fresnel constants at the top of `wet.fx`.
